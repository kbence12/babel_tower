# babel-tower literary benchmark, v1
#
# 200 short English sentences in the style of fiction, each with a Hungarian translation.
# Written from scratch for this project (not taken from any book), so it can be used to test
# a translator trained on book pairs without overlapping its training data.
# Hungarian dialogue follows Hungarian conventions (– dashes instead of quotes).
#
# Format: an "EN:" line followed by its "HU:" line. "##" lines name a section; other "#"
# lines and blank lines are ignored. Use it as a test set only, not for tuning.
